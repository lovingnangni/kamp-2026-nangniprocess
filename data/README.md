# 원본 데이터 준비

이 저장소에는 공식 과제 5 원본 데이터가 포함되지 않습니다. 별도로 보유한 원본 ZIP을 이 폴더의 `KAMP_5_data.zip`으로 배치하세요. ZIP 안에는 원본 CSV 한 개가 있어야 합니다.

| 검사 항목 | 기대값 |
| --- | --- |
| 원본 크기 | 6,168행 × 18열 |
| 잘못된 시간 행 | 48행 |
| 원본 CSV SHA256 | `8f7af2e49366c93e1d6f5fdef4b5e350066c1792ac463c2c2886e370f4674830` |

실행기는 ZIP 압축 바이트가 아니라 내부 CSV의 SHA256을 검사합니다. 원본을 다시 압축해 ZIP 해시가 달라져도 CSV 바이트가 같으면 이 검사를 통과합니다. 임의로 편집하거나 다시 저장한 CSV는 일치하지 않을 수 있습니다.

`--data` 옵션으로 다른 위치의 원본 ZIP을 지정할 수도 있습니다.

```bash
python run_all.py --data /path/to/KAMP_5_data.zip --output outputs
```

원본 데이터의 이용·재배포 조건은 제공처 안내를 따릅니다.
